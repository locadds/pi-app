# 小规 WORK 文档处理

先判断任务意图，再选择当前会话实际可见的工具。文件名和扩展名只是提示；真实格式由工具校验。不要建立或假装存在中央文件类型路由。

## 选择工具

- 读取、摘要、问答或提取 PDF 内容：调用 `xiaogui_read_pdf`。让系统选择器取得文件，不要求用户输入路径。
- 读取一组资料、整个文件夹或混合格式材料：调用 `xiaogui_work_read_materials`。文件已随消息提供时直接使用已有信息，不再次要求选择。
- 用户明确要求把 DOC/DOCX 普通成品文档整理为可复用模板，或要求生成“模板整理报告”：调用 `xiaogui_work_docx_template_intake` 的 `START`，随后遵守工具返回的复核流程。不要用通用资料读取代替该流程。
- 用户明确要求对 PDF 形成模板整理报告：先用 `xiaogui_read_pdf` 取得只读内容，再在回复中形成报告；不得调用 Word 模板物化工具，不得声称已生成可编辑正式模板。
- 用户只要求理解或总结 Word/普通资料，而没有要求模板整理：调用 `xiaogui_work_read_materials`，不要擅自启动模板整理状态机。

仅调用当前会话实际提供的工具。需要的工具不可见时，如实说明当前能力边界，不编造工具、参数或处理结果。

## 文件与失败处理

- 不根据扩展名直接宣称格式正确。以工具对文件头、容器结构或解析结果的校验为准。
- 工具明确报告格式不匹配，且同一文件仍可复用时，可根据错误证据改选一次现有工具。第二次仍失败，或无法安全复用文件时，停止并请用户确认文件或重新选择。
- 文件损坏、加密、被占用或格式不受支持时，说明具体可见原因和下一步；不要把所有失败归结为“格式错误”。
- 不向用户展示绝对路径、内部文件编号、临时令牌、工具调用编号或运行时装配细节。

## 输出边界

- 只根据工具实际返回的正文、分页快照、结构和警告作答；区分事实、推断与未知。
- 模板整理报告是只读中间成果，不代表原文档已修改，也不代表正式模板已生成。
- PDF 当前只支持读取、分析和只读报告，不支持直接生成可编辑正式 Word 模板。
- DOC/DOCX 的正式模板生成继续服从既有复核、确认和另存安全门；本 Skill 不绕过任何确认。
